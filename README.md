# 팔레트 적재 방법 비교 프로그램

「Python 기반 물류 적재 패턴 추천 프로그램 개발」(한다인, 인천해송고등학교) 연구에서 만든 추천 프로그램입니다.

220형, 320형, 420형 상자의 개수와 쌓는 높이를 입력하면 네 가지 적재 방법의 스택 수와 팔레트 수를 비교하고, 팔레트별 상자 수와 트럭 적재 모습을 3D로 보여 줍니다.

## 비교하는 네 가지 방법

| 방법 | 쌓는 방식 |
| --- | --- |
| 높은 상자 우선 | 420형부터 들어갈 수 있는 첫 번째 스택에 넣는다 (First Fit Decreasing) |
| 낮은 상자 우선 | 220형부터 같은 방법으로 넣는다 |
| 높이 조합 우선 | 남은 상자로 만들 수 있는 가장 높은 스택을 하나씩 만든다 |
| 최적 조합 | 정수계획법(SciPy `milp`)으로 스택 수가 가장 적은 조합을 찾는다 |

## 계산 조건

- 상자: 밑면 600×400 mm, 높이 220 / 320 / 420 mm
- 팔레트: 1,100×1,100×150 mm, 팔레트 1개에 스택 4개
- 쌓는 높이: 기본 2,330 mm (짐칸 높이 2,480 mm − 팔레트 150 mm)
- 트럭: 짐칸 10,020×2,400×2,480 mm, 트럭 1대에 팔레트 18개

상자 높이는 외부 높이를 그대로 더해 계산합니다. 상자와 팔레트의 허용 하중, 트럭 적재중량, 화물 고정은 계산에 넣지 않았습니다.

## 실행 방법

Python 3.13에서 실행을 확인했습니다.

1. 이 페이지의 초록색 **Code → Download ZIP**을 눌러 파일을 모두 내려받고 압축을 풉니다.
2. 압축을 푼 폴더에서 터미널을 열고 다음 명령을 차례로 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

실행하면 웹 브라우저에 프로그램 화면이 열립니다.

app.py 파일만 따로 받았다면 첫 번째 명령 대신 다음 명령으로 라이브러리를 설치합니다.

```bash
python -m pip install streamlit scipy plotly numpy
```
